# BF3 -> GMod Pipeline

End-to-end pipeline for porting 32 Battlefield 3 weapons to Garry's Mod with c_hands support.

## Pipeline Stages

1. **Decompile** — Convert BF3 .mdl files into .qc + .smd source files
   - Input: `/home/z/my-project/repos/bf3_sweps_fresh/models/bf3/weapons/*.mdl`
   - Output: `/home/z/my-project/decompile/<weapon>/`
   - Script: `scripts/decompile_all_bf3.py` (requires Crowbar — currently uses existing decompile)

2. **Convert** — Apply c_hands conversion (bone renames, bonemerge, v_hands stripping)
   - Input: `/home/z/my-project/decompile/<weapon>/`
   - Output: `/home/z/my-project/compile/<weapon>/source/`
   - Scripts:
     - `scripts/simple_c_hands.py` — Main conversion (bone renames, bonemerge, mesh strip)
     - `scripts/fix_bone_names.py` — Post-fix for "(null)" and "b_root" bone names

3. **Edit** — Optional: edit SMD files (Blender with SourceIO) or QC files (text editor)

4. **Compile** — Compile source files back into .mdl + .vvd + .vtx
   - Input: `/home/z/my-project/compile/<weapon>/source/<weapon>.qc`
   - Output: `/home/z/my-project/compile/<weapon>/compiled/`
   - Script: `scripts/recompile_all.py`
   - Compiler: `studiomdl` (built from source-sdk-2013 with intptr_t fixes)

5. **Package** — Bundle all compiled files for Garry's Mod
   - Output: `/home/z/my-project/compile/Battlefield3/` (192 files = 32 weapons × 6 variants)

## Prerequisites

- **studiomdl binary** at `repos/source-sdk-2013/game/bin/studiomdl`
  - Built with `kalloc intptr_t fix` (studiomdl.cpp line 334)
  - Built with `ALIGN macros intptr_t fix` (write.cpp lines 66-70)
  - Built with `LoadMaterialSystem graceful degradation` (matsys.cpp)

- **filesystem_stdio.so stub** at `repos/source-sdk-2013/game/bin/bin/linux64/`
  - Generated by `scripts/build_stub/gen_fs_stub.py`
  - Implements IFileSystem interface for studiomdl's file I/O

- **c_arms_definebones.qci** at `/tmp/c_arms_extract/`
  - Extracted from `repos/gmod-animations/c_medkit.7z` (run `7z x c_medkit.7z`)

- **libtier0.so + libvstdlib.so** at `repos/source-sdk-2013/src/lib/public/linux64/`
  - Shipped with source-sdk-2013

## Usage

```bash
# Show pipeline status
python3 scripts/pipeline.py status

# Run full pipeline (convert + compile, all 32 weapons)
python3 scripts/pipeline.py full

# Run for a single weapon
python3 scripts/pipeline.py full m416

# Just compile (without re-converting)
python3 scripts/pipeline.py compile

# Clean compiled files
python3 scripts/pipeline.py clean
```

## Key Fixes Applied

### 1. studiomdl 32-bit/64-bit pointer truncation (kalloc)
**File:** `repos/source-sdk-2013/src/utils/studiomdl/studiomdl.cpp` (line 334)
**Before:** `ptr = (byte *)((int)((byte *)ptr + 511) & ~ 511);`  // truncates to 32 bits!
**After:**  `ptr = (byte *)((intptr_t)((byte *)ptr + 511) & ~ (intptr_t)511);`

### 2. studiomdl ALIGN macros (write.cpp)
**File:** `repos/source-sdk-2013/src/utils/studiomdl/write.cpp` (lines 66-70)
Changed all ALIGN4/16/32/64/512 macros to use `intptr_t` instead of `int`.

### 3. studiomdl LoadMaterialSystem graceful degradation
**File:** `repos/source-sdk-2013/src/utils/studiomdl/matsys.cpp`
Changed `MdlError` calls to `Warning` calls so studiomdl continues without materialsystem.so.

### 4. filesystem_stdio.so stub
**File:** `scripts/build_stub/gen_fs_stub.py` (auto-generates C++ stub)
Implements the IFileSystem interface (~135 virtual methods) using POSIX file I/O.
IsSteam() returns false (critical — studiomdl refuses to mount if true).

### 5. Bone name fixes
**File:** `scripts/fix_bone_names.py`
- Renames `"(null)"` root bone to `"ValveBiped.Bip01_Root"` (m9, g18, m1911, m93r, mp443)
- Renames `"b_root"` to `"ValveBiped.Bip01"` (g3a3)
- Re-applies BONE_MAP to QC files that weren't renamed (famas)

# World War II — Underhell

TFA World War II weapons ported to the CUH (Customizable UnderHell) base.

This folder contains all ported WWII weapons, attachments, sounds, and materials
from the TFA WWII mod, converted to work with the CUH base.

## Structure

```
worldwarii_underhell/
├── lua/
│   ├── weapons/          # Ported weapon files
│   ├── cuh_attachments/   # Ported attachment files
│   └── autorun/          # Sound scripts and other autorun files
├── models/               # World models, view models, attachment models
├── materials/             # Weapon skins, attachment icons, HUD elements
├── sound/                # Fire sounds, reload sounds, foley
└── addon.json            # GMod addon metadata
```
